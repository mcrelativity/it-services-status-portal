Portal de Monitoreo de Servicios TI

Esta aplicación comprueba si servicios externos utilizados por el proyecto están disponibles. Cada vez que se abre o actualiza esta página, el servidor realiza una solicitud HTTP real a cada endpoint y registra código de respuesta, latencia y hora del chequeo.

¿Qué significa “Operativo”? El endpoint respondió con un código HTTP entre 200 y 399 dentro de {{ timeout_seconds }} segundos. Si no responde, excede el tiempo máximo o devuelve un error HTTP, se marca como “No disponible”.

¿Qué servicios se monitorean?

Se supervisan dependencias públicas relacionadas con el desarrollo y despliegue de la solución: GitHub API, PyPI, Python.org y AWS. El objetivo es demostrar monitoreo real sin utilizar credenciales ni sistemas privados. Este es un entorno académico y no representa monitoreo productivo de una empresa.

¿Cómo funciona?

  1. El usuario abre la página o consulta /api/services.
  2. FastAPI ejecuta en paralelo un chequeo HTTP a los cuatro endpoints.
  3. Se mide el tiempo de respuesta y se obtiene el código HTTP.
  4. La aplicación clasifica el resultado y muestra la evidencia del chequeo.
  5. La versión del software se despliega automáticamente desde GitHub Actions hacia AWS.
